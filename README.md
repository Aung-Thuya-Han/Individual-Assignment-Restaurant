# Student Restaurants - Grade 1 Version

## What this version contains

- A semantic HTML page structure.
- A responsive CSS layout for desktop, tablet, and mobile widths.
- Restaurant data loaded from the Student Restaurants API.
- Automatic area selection based on the user's location.
- The location result is reused during the same browser session.
- An area dropdown for manually choosing another town or city.
- Restaurants sorted from nearest to farthest when location is available.
- A button for selecting a restaurant.
- Daily and weekly menu buttons.
- Live menu data for the selected restaurant.
- Loading, empty, and error messages.
- Registration and login using the Metropolia backend.
- A profile page for updating username, email, password, and profile picture.
- A saved authentication token so the user stays logged in after reloading.
- Favorite buttons for logged-in users.
- A separate local favorite-restaurant list for each user in the browser.
- Favorite restaurant names and addresses on the profile page.

## What this version does not contain yet

- Favorites shared between different browsers or devices.
- Maps.
- Public deployment.
- A published source-code repository.

## How to view the page

Open `indivi_assignment.html` with Live Server. An internet connection is needed
because the restaurant and menu information comes from the API. Allow location
access to use automatic area selection and distance sorting. If location is not
available, choose an area from the dropdown list.
